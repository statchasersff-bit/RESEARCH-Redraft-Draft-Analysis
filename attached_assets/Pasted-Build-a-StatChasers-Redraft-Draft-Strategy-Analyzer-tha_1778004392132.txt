Build a StatChasers “Redraft Draft Strategy Analyzer” that studies the last 5 years of completed Sleeper redraft leagues and identifies which draft strategies produced the best fantasy results.

IMPORTANT:
Do this one step at a time. First build the backend/data pipeline and JSON outputs. Do not redesign the public UI until the data pipeline works.

PROJECT GOAL
Create a data-backed guide/tool that answers:

“What is the optimal fantasy football redraft draft strategy based on real Sleeper draft results?”

The analyzer should compare draft strategies by:
- Draft slot
- First-round position
- First two picks
- First five rounds
- Scoring format
- League size
- 1QB vs Superflex
- Final team success

DATA SOURCE
Use Sleeper public API.

We need to analyze completed redraft leagues from the last 5 NFL seasons.

Use only leagues that are:
- Redraft leagues
- Completed seasons
- Not dynasty
- Not keeper
- Not best ball, unless clearly separated
- Prefer 10-team and 12-team leagues
- Prefer standard roster formats where possible

For each league, pull:
- League metadata
- League settings
- Scoring settings
- Roster positions
- Users
- Rosters
- Matchups
- Winners bracket / playoff bracket if available
- Draft IDs
- Draft results / draft picks

Sleeper endpoints likely needed:
- GET /league/{league_id}
- GET /league/{league_id}/users
- GET /league/{league_id}/rosters
- GET /league/{league_id}/matchups/{week}
- GET /league/{league_id}/winners_bracket
- GET /league/{league_id}/losers_bracket
- GET /league/{league_id}/drafts
- GET /draft/{draft_id}
- GET /draft/{draft_id}/picks
- GET /players/nfl

LEAGUE VALIDATION
Before analyzing a league, validate it.

Skip league if:
- League is dynasty
- League is keeper
- League has no draft
- League has incomplete draft data
- League has missing rosters
- League has no matchup data
- League size is less than 8 or greater than 14
- Draft type appears to be auction, unless supported
- Best ball is detected, unless separated

For each valid league, classify:
- season
- league_size
- scoring_format
- roster_format
- draft_type

SCORING FORMAT CLASSIFICATION
Classify scoring format based on receptions:

- Standard: rec = 0
- Half PPR: rec = 0.5
- PPR: rec = 1
- Other PPR: anything else

ROSTER FORMAT CLASSIFICATION
Classify roster format:

- Superflex if roster_positions includes SUPER_FLEX or OP
- 1QB if no SUPER_FLEX / OP and only one QB starter
- 2QB if two QB slots
- Other if unclear

DRAFT SLOT GROUPS
For 12-team leagues:
- Early: draft slots 1-4
- Middle: draft slots 5-8
- Late: draft slots 9-12

For 10-team leagues:
- Early: 1-3
- Middle: 4-7
- Late: 8-10

For other league sizes, divide into thirds as evenly as possible.

STRATEGY CLASSIFICATIONS
Classify each team into strategy buckets.

Zero RB:
- 0 RBs selected in rounds 1-5

Hero RB:
- exactly 1 RB selected in rounds 1-5

Robust RB:
- 3 or more RBs selected in rounds 1-5

WR Heavy:
- 3 or more WRs selected in rounds 1-5

Elite QB:
- QB selected in rounds 1-4

Elite TE:
- TE selected in rounds 1-4

Balanced Start:
- through Round 5, team has:
  - at least 1 RB
  - at least 1 WR
  - no more than 1 QB
  - no more than 1 TE
  - at least 4 total RB/WR picks

Fragile RB:
- exactly 2 RBs in rounds 1-5
- no RBs in rounds 6-8

Late QB:
- first QB selected round 8 or later

Late TE:
- first TE selected round 8 or later

Anchor TE:
- TE selected rounds 1-3

Double Hero RB:
- exactly 2 RBs selected in rounds 1-5
- at least 3 WRs selected in rounds 1-6

Do not force teams into only one strategy. A team can belong to multiple strategy buckets.

ANALYSIS OUTPUTS
For every strategy bucket and combo, calculate:

- sample_size
- average_points_for
- median_points_for
- average_wins
- playoff_rate
- finals_rate
- championship_rate
- top_3_pf_rate
- average_final_standing
- confidence_level

Confidence level:
- High: sample_size >= 250
- Medium: sample_size >= 75
- Low: sample_size >= 25
- Very Low: sample_size < 25

Only show “recommended” strategies if sample size is at least 75.

Recommendation rules:

- Always include sample size.
- Prefer playoff rate, top-3 PF rate, and championship rate over average wins alone.
- Flag when championship rate and playoff rate disagree.
- Include “confidence” for each recommendation.

STATISTICAL BASELINES
Calculate overall baseline rates:

- overall playoff rate
- overall finals rate
- overall championship rate
- overall top_3_pf_rate
- average points for

Then for each strategy, calculate lift vs baseline:

- playoff_rate_lift
- championship_rate_lift
- top_3_pf_rate_lift
- points_for_lift

Example:
If baseline playoff rate is 41.7% and WR/WR starts make playoffs 49.2%, playoff_rate_lift = +7.5 percentage points.

IMPORTANT:
Use percentage point differences, not relative percentage increases.
